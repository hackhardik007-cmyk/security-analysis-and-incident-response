# Evidence and Screenshots

This directory intentionally contains no screenshots by default.

Before adding evidence:
1. Confirm that you are permitted to publish it.
2. Redact usernames, email addresses, tokens, passwords, private IPs, public target identifiers, session IDs, and unrelated desktop information.
3. Do not upload malware samples, payload binaries, recovered credentials, hashes, raw scanner output, or files that could expose a third-party system.
4. Add a short caption and explain what the screenshot demonstrates.
5. If authorization is uncertain, leave the evidence out and keep the original report private.
